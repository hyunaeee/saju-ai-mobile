# 천기연 배포 안내 (실서비스 오픈까지)

> ## 배포 주소 (2개로 분리됨)
>
> | 용도 | 주소 | 상태 |
> |---|---|---|
> | 🎬 **데모** (홍보·시연·공유용) | https://saju-ai-mobile-demo.vercel.app | **영구 데모 잠금** — 키를 넣어도 결제 안 켜짐 |
> | 🚀 **실서비스** | https://saju-ai-mobile.vercel.app | 키 입력 시 실서비스 ON (지금은 데모 표시) |
>
> - GitHub: https://github.com/hyunaeee/saju-ai-mobile (private)
> - 실서비스 주소에 나중에 자체 도메인(`cheongiyeon.co.kr` 등)을 연결합니다.
> - 데모 잠금은 `js/config.js`의 `DEMO_HOSTS` 목록으로 제어됩니다.

이 문서 하나만 따라 하면 실제로 돈을 받는 서비스로 올라갑니다.
지금 상태로도 **로컬/배포 즉시 "데모 모드"로 완전히 동작**하며, 아래 3~5단계를 마치면 **실결제·AI 답변이 켜지는 "실서비스 모드"**로 전환됩니다.

## 0. 지금 구조 한눈에

```
정적 파일 (프론트)          서버리스 함수 (백엔드, /api)
├─ index.html  플랫폼 홈         ├─ api/confirm.js   결제 승인 검증 → 접근토큰 발급
├─ saju.html   연화 사주         ├─ api/report.js    결제자에게만 심층 리포트 본문 생성
├─ party.html  모임 관계         ├─ api/ask.js       질문 답변 (claude-haiku-4-5)
├─ cosmos.html 오늘의 하늘       ├─ api/party.js     모임 실시간 공유 (Upstash KV)
├─ privacy.html / terms.html    └─ api/_lib.js      토큰 서명·가격표·엔진 로드
├─ css/  style.css(사주 페이지) · nav.css(공통 탭바)
├─ js/   config.js ← 실서비스 전환 스위치 (여기 2줄만 수정)
│        saju.js(만세력 엔진, 서버 공용) · content.js(해석 텍스트, 서버 공용)
│        lunar.js(음↔양력) · app.js(사주 페이지) · party.js · cosmos.js
├─ assets/  이미지·영상·행성 텍스처
└─ docs/    이 문서 · 실행체크리스트
```

- **데모 모드** (config.js의 tossClientKey 비어 있음): 결제·리포트·질문이 전부 브라우저에서 처리됩니다. 지금 상태.
- **실서비스 모드** (tossClientKey 채움): 결제는 토스 결제창 → 서버가 승인 검증, 리포트 본문은 서버 생성, 질문은 서버에서 Claude 호출. API 키는 서버에만 보관됩니다.

## 1. 사업 준비 (직접 · 결제의 전제조건)

1. **사업자등록** (홈택스, 무료) — 업종: 전자상거래 / 온라인 정보제공업
2. **통신판매업 신고** (정부24, 등록면허세 약 4만원/년)
3. 위에서 받은 정보로 아래 파일의 `[대괄호]` 부분을 채우세요.
   - `index.html`(홈)·`saju.html`(사주) 푸터의 상호·대표·사업자번호·통신판매업신고번호
   - `privacy.html` 하단 보호책임자/사업자 정보
   - `terms.html` 하단 사업자 정보
   - 고객센터 이메일(`help@cheongiyeon.example`)을 실제 주소로 일괄 교체

> 운세·사주 콘텐츠는 PG 심사에서 일반적으로 승인되는 업종입니다. 위 법적 페이지(약관·개인정보처리방침·환불정책)가 있어야 심사를 통과합니다 — 이미 만들어져 있습니다.

## 2. 토스페이먼츠 가입 (직접)

1. [토스페이먼츠](https://www.tosspayments.com) 가입 → 심사(사업자 필요)
2. **정산받을 계좌(내 통장)** 등록 → 결제금이 이 계좌로 자동 정산(보통 D+2)
3. **API 키 2개** 발급:
   - 클라이언트 키 `test_ck_...` / `live_ck_...` (공개되어도 되는 키)
   - 시크릿 키 `test_sk_...` / `live_sk_...` (**절대 노출 금지**, 서버에만)

## 3. 배포 (Vercel — 가장 간단)

```bash
npm i -g vercel      # 최초 1회
cd saju-ai-test
vercel               # 로그인 후 안내에 따라 배포 → https://your-app.vercel.app 발급
```

배포 후 **Vercel 대시보드 → 프로젝트 → Settings → Environment Variables** 에 등록
(`.env.example` 참고, 값은 서버에만 저장됨):

| 이름 | 값 |
|---|---|
| `TOSS_SECRET_KEY` | 토스 시크릿 키 (`test_sk_...` → 심사 후 `live_sk_...`) |
| `TOKEN_SECRET` | 긴 랜덤 문자열. 생성: `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"` |
| `ANTHROPIC_API_KEY` | Claude API 키 (질문 답변용). 미설정 시 템플릿 답변으로 자동 폴백 |

등록 후 재배포: `vercel --prod`

## 4. 실서비스 모드 켜기 (스위치 2줄)

`js/config.js` 를 열고 두 값만 채웁니다:

```js
window.CHEONGIYEON_CONFIG = {
  apiBase: "",                       // 같은 도메인에 배포했으면 "" 그대로
  tossClientKey: "test_ck_...",      // 토스 클라이언트 키 (여기 채우면 실서비스 모드 ON)
};
```

다시 `vercel --prod`. 이제 결제 버튼이 토스 결제창을 띄우고, 승인은 서버가 검증합니다.

## 5. 테스트 → 오픈

1. `test_ck_/test_sk_` 로 [토스 테스트 카드](https://docs.tosspayments.com/reference/testing)로 결제 테스트
2. 결제 → 리포트 잠금 해제 → 질문 답변 → 환불 정책 동의 흐름 확인
3. 이상 없으면 토스 실키(`live_ck_/live_sk_`)로 교체하고 오픈

## 6. 오픈 후 권장 (선택)

- **후기 교체**: `saju.html`의 후기 3개는 데모 샘플입니다. 허위 후기는 표시광고법 위반이니 실제 후기로 교체하거나 내리세요.
- **카카오 공유 키**: [developers.kakao.com](https://developers.kakao.com) JS 키 → `js/app.js` 상단 `KAKAO_JS_KEY`
- **주문/제공 이력 DB**: 지금은 무DB(서명 토큰)로 동작합니다. 환불 분쟁 대비와 질문 5개 서버 차단을 위해 Vercel KV(또는 Postgres)에 주문·제공시점·질문사용수를 저장하면 좋습니다. 관련 위치에 `TODO [실서비스]` 주석을 달아두었습니다.
- **콘텐츠 완전 보호(선택)**: 현재 `js/content.js`가 브라우저로도 전송되어, 마음먹으면 소스에서 유료 문구를 볼 수 있습니다(실사용자엔 사실상 무의미). 완전 차단을 원하면 `js/content.js`의 프리미엄 문구 뭉치를 서버 전용 파일로 옮기고 `saju.html`에서 제외하면 됩니다. 결제 검증과 AI 키 보호(실제 비용이 드는 부분)는 이미 서버에서 안전하게 처리됩니다.

## 상품·가격 — 코인 시스템

**결제 심리 설계**: 사용자는 콘텐츠를 코인으로 열고, 코인은 몇천원 단위로 충전합니다.
"돈을 낸다"가 아니라 "코인을 쓴다"로 느끼게 하는 구조 + 무료 코인/광고 적립으로 진입 장벽을 낮춥니다.

**코인 충전 패키지** (토스 결제, `js/coins.js`·`api/_lib.js` 동기화 필수):

| 패키지 | 코인 | 가격 | 코인당 |
|---|---|---|---|
| coin_c5 | 5 | 4,900원 | 980원 |
| coin_c12 | 13 (+1) | 9,900원 | 762원 |
| coin_c30 | 35 (+5) | 19,900원 | 569원 |

**콘텐츠 가격 (코인)** — 페이지당 버튼 1개 + 패스 1개 구조 (조각 결제 방지):

| 상품 | 코인 | 내용 |
|---|---|---|
| report | 9 | 사주 심층 풀이 17섹션 |
| questions | 7 | 연화에게 질문 5개 |
| group | 6 | 모임 궁합 |
| wish | 4 | 소원부적 |
| spouse | 8 | 배우자 리포트 **전체** 16섹션 (몽타주·체형 포함) |
| career | 8 | 직업운 리포트 **전체** |
| verify | 5 | 궁합 검증 (일치율·궁합·시기) |
| **allpass** | **18** | **전 서비스 패스 — 위 전부** (개별 합 47코인 상당) |

패스는 `productsFor("allpass")`가 모든 권한을 부여하고, 프론트는 `cheongiyeon_own_<sig>.allpass`를
배우자·직업·검증 페이지에서 함께 인식합니다(어느 페이지에서 사도 전 서비스 해제).

**무료 적립**: 웰컴 3코인(브라우저 기준) · 광고 시청 +1코인(일 3회, 현재 데모 시뮬레이션 —
실서비스는 카카오 애드핏/AdSense H5 게임형 보상 광고 또는 쿠팡 파트너스로 교체, `Coins.adHook`에 연결).

**보안**: 실서비스에서 코인 원장은 Upstash KV(`api/wallet.js`)가 관리 — 충전은 토스 검증 후 서버가 적립,
사용은 서버가 차감 후 접근 토큰 발급. KV 미설정 시 로컬 지갑으로 자동 폴백(시연용).

기존 원화 단품 결제도 결제 모달에 그대로 남아 있어 병행 판매됩니다.
결제 수수료(약 2~3%)를 빼도 코인 1개당 원가는 ≈0원(질문만 Claude 호출 ≈8원/건)입니다.
